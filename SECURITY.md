# Политика безопасности

Русский | [English](SECURITY.en.md)

Грань UI загружает разметку, шрифты и картинки из файлов и работает напрямую с памятью видеокарты, поэтому
ошибки безопасности для нас — самые важные.

## Поддерживаемые версии

Выпусков пока нет: движок в разработке, исправления вносятся в ветку `main`.

| Версия | Поддержка |
|---|---|
| `main` | ✅ исправления безопасности |

## Как сообщить об уязвимости

**Не открывайте публичную задачу (issue) и не пишите в обсуждения** — так уязвимость станет известна раньше исправления.

Сообщите закрыто через GitHub: [Security → Report a vulnerability](https://github.com/ErmaleyAlekov/Gran-UI/security/advisories/new). Если доступа к GitHub нет — по электронной почте [ermaley.alekov@yandex.ru](mailto:ermaley.alekov@yandex.ru) с темой «Безопасность: Gran UI».

В сообщении укажите:

- коммит или версию движка, ОС, компилятор, видеокарту и версию драйвера;
- минимальную разметку, шрифт или картинку, на которых проявляется ошибка, и что происходит (падение, зависание, рост памяти, чтение чужого файла, потеря устройства, ошибка отладочного слоя D3D12);
- если есть — оценку последствий.

## Что дальше

- Подтверждение получения — в течение 7 дней.
- Оценка и план исправления — в течение 30 дней; о сроках сообщим заранее.
- Исправление выходит на GitHub и Gitverse; в описании GitHub Security Advisory будет указан автор сообщения (если он не против).

## Что считается уязвимостью

- Падение, выход за границы памяти, утечка или неопределённое поведение на любой разметке, файле PNG или шрифте TrueType/TTC.
- Обход лимитов: размеры картинки и результата inflate, глубина разметки, вложенность составных глифов.
- Загрузка внешних ресурсов XML (DTD, XInclude) при разборе разметки.
- Выполнение из разметки чего-либо, кроме действий, которые программа сама связала с функциями C++.
- Передача объектов программы в скрипт страницы `<WebView>` в обход строкового моста.
- Запись за пределы буфера видеокарты, чтение шейдером за пределами данных, использование ресурса после удаления.

Не уязвимость: ошибки отрисовки и компоновки без влияния на безопасность, отказ загрузить разметку, не прошедшую схему, — о них пишите в обычные задачи. Ошибки разбора XML и схемы относятся к [«Берёсте»](https://github.com/ErmaleyAlekov/beresta/blob/main/SECURITY.md).
