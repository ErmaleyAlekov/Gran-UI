# Ручные проверки (человек в контуре)

Автотесты, санитайзеры и отладочные слои GPU не видят всего: как выглядит кадр, как окно ведёт себя под живой мышью,
что показывает захват кадра на настоящей видеокарте, что происходит за часы работы. Такие проверки делает человек
по подробным задачам. Задачи готовятся после каждой большой доработки (правило проекта: автотесты + анализаторы +
ручные задачи), файлы — в [`tasks/`](tasks/).

## Как устроена задача

`## Т-<номер>. <название>` и поля: **Зачем** (риск, который проверяем, и почему автоматика его не видит),
**Приоритет** и время, **Подготовка** (точные команды), **Шаги**, **На что смотреть**, **Что прислать**,
**Результат** (заполняет проверяющий) и **Разбор** (заполняет разработчик: что исправлено, какая автоматическая
проверка добавлена, чтобы в следующий раз ловить это без человека).

Приоритеты: **блокирует выпуск** — без этой проверки версию не выпускаем; **до выпуска** — желательно;
**когда будет время** — полезно, но не срочно.
