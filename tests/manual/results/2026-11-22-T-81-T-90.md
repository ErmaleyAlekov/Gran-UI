# Результаты ревью Т-81…Т-90

## Результат

Координаты относятся к версии кода на момент ревью.

- **Т-81.** В `src/undo/undo_info.cpp:29` вычисление `std::size_t keep = _index + limit;` приводит к беззнаковому переполнению (нарушение О-2), когда в непустой стек передают большой предел вроде `SIZE_MAX` или `limit > SIZE_MAX - _index`. Вместо сложения нужно сравнивать `limit < _steps.size() - _index`.
- **Т-83.** В `src/app/task_pool_run.cpp:23` внутри `DeliverDone::operator()` вызывается `record->pool->forget(record->outcome.id)`, где `record->pool` является сырым указателем на `TaskPool` (`src/app/task_pool.cpp:80`), а деструктор `TaskPool::~TaskPool()` (`src/app/task_pool.cpp:49`) дожидается только рабочих потоков и не отменяет задачи, уже отправленные в очередь UI через `_poster`. В случае `DeliverProgress` (`src/app/task_progress.cpp:60`) потеря доставки при исключении в `_poster` оставляет `record->progressQueued = true` навсегда, полностью блокируя все последующие уведомления о прогрессе для этой задачи.
- **Т-85.** В `src/rhi/vulkan/vulkan_swapchain.cpp:20` после запроса `vkGetPhysicalDeviceSurfaceCapabilitiesKHR` проверяется только случай `caps.currentExtent.width == UINT32_MAX`, но не проверяется `caps.currentExtent.width == 0 || caps.currentExtent.height == 0`, после чего `_swapExtent` напрямую передаётся в `vkCreateSwapchainKHR` на строке `src/rhi/vulkan/vulkan_swapchain.cpp:29`. При сворачивании окна WSI может вернуть `{0, 0}`, пока сохранённый размер окна ещё ненулевой (`vulkan_frame.cpp:52`, `vulkan_backend.cpp:60`).
- **Т-86.** В `src/text/raster/raster_accumulator.cpp:27,43` ограничение `limit = width - 1.001f` искажает покрытие последнего столбца. Воспроизводится вертикальным ребром с координатой `x = width - 0.5f`. В `src/vector/shape_raster.cpp:52,62` в функции `feedPath` не проверяется достаточность элементов в `path.points` для каждого шага `Verb` и наличие `Verb::MOVE` в начале контура.
- **Т-88.** В файле `src/image/jpeg_scan_header.cpp:67` функция `readScanHeader` не проверяет уникальность идентификаторов компонент в списке SOS. В `src/image/jpeg_segments.cpp:65` проверка границ сегмента через сложение может переполниться вблизи предела `size_t`.
- **Т-89.** В `src/binding/expression_update.cpp:81` сбрасываются флаги `binding.stale` и `binding.forced`, а затем в `src/binding/expression_evaluate.cpp:104` обновляются версии зависимостей `seen` до вычисления частей выражения. Исключение из `toView` оставляет привязку со старым значением. В `src/binding/expression_update.cpp:54` удаление предшествующей привязки через `forget` сдвигает вектор и пропускает следующую привязку в этом кадре. Записи по сохранённому индексу (`expression_update.cpp:108,118`) после первой перестановки могут попасть в другую строку.
- **Т-90.** В `src/markup/component_expand.cpp:74,80,84` адрес локального объекта `scope` записывается в `context.scope`. Исключение из `buildNode` обходит восстановление области. В `src/markup/component_slots.cpp:36,47` переключение области при построении детей слота также не защищено при исключениях. В `component_slots.cpp:55,58` `collectSlots` не проверяет повторное объявление безымянного слота. В `component_values.cpp:52` числовой литерал из значения по умолчанию или токена темы попадает в составное выражение без проверки формата. В `component_expand.cpp:44,49` проверка циклов не ограничивает глубину цепочки разных компонентов и число развёрток.

## Разбор

Ссылки указывают на исправленный код.

- **Т-81.** Максимальный предел истории переполнял сумму с курсором и удалял доступные для повтора шаги. Предел сравнивается с числом шагов справа от курсора до сложения. [`undo_info.cpp:27`](../../../src/undo/undo_info.cpp#L27)
- **Т-83.** Очередь интерфейса могла доставить итог после уничтожения пула. Ошибка постановки прогресса в очередь оставляла признак ожидающей доставки. Доставки учитывают остановку пула, а неудачная постановка освобождает признак прогресса или запись завершённой задачи. [`task_pool_run.cpp:16`](../../../src/app/task_pool_run.cpp#L16), [`task_progress.cpp:50`](../../../src/app/task_progress.cpp#L50)
- **Т-85.** При нулевом размере поверхности Vulkan получал запрос создать swapchain с недопустимым размером. Пересоздание откладывается до появления ненулевого размера, а кадр получает статус `OCCLUDED`. [`vulkan_swapchain.cpp:8`](../../../src/rhi/vulkan/vulkan_swapchain.cpp#L8), [`vulkan_frame.cpp:41`](../../../src/rhi/vulkan/vulkan_frame.cpp#L41)
- **Т-86.** Ограничение координат обрезало покрытие правого столбца, а некорректный `Path` мог читать за концом массива точек. У каждой строки накопителя есть собственная граничная ячейка, контуры проверяются до растеризации. [`raster_accumulator.cpp:10`](../../../src/text/raster/raster_accumulator.cpp#L10), [`shape_frame.cpp:12`](../../../src/vector/shape_frame.cpp#L12)
- **Т-88.** Заголовок JPEG SOS принимал повторяющиеся идентификаторы компонент. Проверки длины сегмента могли переполниться. Дубликаты отклоняются, длины проверяются по остатку входного буфера. [`jpeg_scan_header.cpp:41`](../../../src/image/jpeg_scan_header.cpp#L41), [`jpeg_segments.cpp:58`](../../../src/image/jpeg_segments.cpp#L58)
- **Т-89.** Исключение преобразователя могло лишить привязку повторного вычисления, удаление привязок в обратном вызове нарушало перебор, а перестановка строк меняла индекс живой копии. После исключения привязка повторяет вычисление и сохраняет возможность передать правку пользователя обратно в источник. Удалённые привязки пропускаются. Перед каждой отложенной записью определяется текущая строка сохранившегося узла. [`expression_update.cpp:33`](../../../src/binding/expression_update.cpp#L33), [`expression_evaluate.cpp:75`](../../../src/binding/expression_evaluate.cpp#L75)
- **Т-90.** При ошибке развёртки или построения слота область видимости оставалась изменённой. Область восстанавливается при любом выходе, повторное объявление безымянного слота и неправильные числовые литералы отклоняются, развёртка ограничена по глубине и объёму работы. [`component_expand.cpp:41`](../../../src/markup/component_expand.cpp#L41), [`component_slots.cpp:29`](../../../src/markup/component_slots.cpp#L29), [`component_values.cpp:43`](../../../src/markup/component_values.cpp#L43)
