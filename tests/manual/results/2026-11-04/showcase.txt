
1. Event Browser & ResourceBarrier

В данном кадре зафиксировано выполнение проходов размытия подложки (blur pass):
• Количество вызовов DrawInstanced: 4 вызова. Они соответствуют этапам уменьшения (psBlurDown — 2 вызова) и увеличения разрешения (psBlurUp — 2 вызова).
• Количество барьеров ResourceBarrier: 5 барьеров. Они обеспечивают синхронизацию текстур при смене шейдерных проходов.

2. Состояния барьеров для swapchain и текстур

• Буфер кадра swapchain (gran.backBuffer1): Зафиксирован 1 переход в состояние RENDER_TARGET в самом начале кадра и ровно 1 обратный переход в состояние PRESENT в конце кадра перед выводом.
• Текстуры размытия: Все переходы состояний строго скоординированы. Обнаружено 4 парных перехода вида RENDER_TARGET -> PIXEL_SHADER_RESOURCE. Лишних или дублирующих переходов в то же самое состояние не зафиксировано.

3. Pipeline State → Output Merger (Смешивание)

В блоке Output Merger для проходов смешивания установлены следующие параметры:
• SrcBlend: ONE (численный идентификатор в API = 1)
• DestBlend: INV_SRC_ALPHA (численный идентификатор в API = 6)

4. Mesh/Buffer viewer (Параметры экземпляров)

При анализе параметров отрисовки мешлетов через буфер m_MeshletBuf получены следующие данные:
• InstanceCount (число экземпляров): 1 экземпляр (InstanceCount = 1).
• Размер структуры заголовка GpuInstance: 32 байта.
• Итоговый размер данных экземпляров: 1 × 32 = 32 байта.
• Размер буфера экземпляров: Буфер m_ReadbackBuffer имеет размер 64 байта. Условие инструкции соблюдено: размер структуры (32 байта) не превышает общий размер буфера (64 байта).

5. Texture Viewer (Атласы и текстуры)

• Атлас глифов (gran.glyphAtlas): Текстура содержит 1 отрендеренный срез (слой) с глифами. Символы четкие, без наложений и артефактов.
• Текстуры картинок (gran.gradientRamps): В куче текстур зафиксировано ровно 2 градиентные рампы. Изображения корректные, без полос и сдвигов строк.

6. Performance Counters / Timeline (AMD GPU)

• Видеокарта: Захват кадра производился на графическом процессоре AMD Radeon RX 9070.
• Время кадра на GPU: Согласно счетчикам на временной шкале очереди gran.queue, общее время выполнения данного кадра на GPU составило 2.14 мс.
