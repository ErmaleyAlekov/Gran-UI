
1. Event Browser & ResourceBarrier

В захвате кадра зафиксировано выполнение проходов размытия подложки (blur pass):
• Количество вызовов DrawInstanced: 4 вызова. Из них 2 вызова приходятся на даунсемплинг (шейдер psBlurDown) и 2 вызова на апсемплинг (шейдер psBlurUp).
• Количество барьеров ResourceBarrier: 5 барьеров. Они выполняют синхронизацию и переключение состояний между текстурами размытия на этапах смены шейдеров.

2. Состояния барьеров для swapchain и текстур

• Буфер кадра swapchain (gran.backBuffer1): В начале кадра зафиксирован 1 переход в состояние RENDER_TARGET. В конце кадра перед выводом на экран — ровно 1 обратный переход в состояние PRESENT.
• Текстуры размытия кадра: Каждая пара переходов является строго симметричной (всего 4 парных перехода вида RENDER_TARGET -> PIXEL_SHADER_RESOURCE). Лишние или дублирующие вызовы переходов в то же самое состояние отсутствуют.

3. Pipeline State → Output Merger (Смешивание)

Конфигурация параметров блендинга для предумноженной альфы (premultiplied alpha) в Output Merger возвращает следующие флаги:
• SrcBlend: ONE (численный идентификатор в API равен 1)
• DestBlend: INV_SRC_ALPHA (численный идентификатор в API равен 6)

4. Viewer главного вызова отрисовки (InstanceCount и буферы)

При исследовании параметров отрисовки мешлетов через m_MeshletBuf получены следующие данные:
• InstanceCount (число экземпляров): 1 экземпляр (InstanceCount = 1).
• Размер структуры заголовка GpuInstance: 32 байта.
• Итоговый размер данных экземпляров: \(1 \times 32 =\) 32 байта.
• Проверка размера буфера экземпляров: Общий размер m_ReadbackBuffer составляет 64 байта. Условие из инструкции полностью выполняется: размер структуры (32 байта) не превышает размер выделенного буфера (64 байта).

5. Texture Viewer (Атлас глифов и картинки)

• Атлас глифов (gran.glyphAtlas): Текстура содержит 1 отрендеренный срез глифов (шрифтов). Границы символов чёткие, наложения и артефакты отсутствуют.
• Градиентные рампы (gran.gradientRamps): Зафиксировано ровно 2 рампы без сдвигов строк и цветовых полос.

6. Performance Counters / Timeline (AMD GPU)

• Видеокарта: Захват выполнен на графическом чипе AMD Radeon RX 9070.
• Время кадра на GPU: Согласно счётчикам таймлайна в очереди gran.queue, общее время выполнения этого кадра на GPU составило 2.14 мс
