# Ручные проверки: строка состояния StatusBar (0.2.0, часть 4 плана 2.1), 2026-11-10

Автотесты (`status_bar_tests.cpp`) проверяют ручку размера (вид, роль `resize` по точке), текст секции и поиск
сменившихся секций для дикторов. Чего они не видят: настоящее изменение размера окна за ручку (ОС ведёт его сама:
Windows по ответу `HTBOTTOMRIGHT`, X11 — `_NET_WM_MOVERESIZE`), курсор над ручкой, речь диктора.

## Т-32. Ручка размера окна и курсор (Windows, Linux)

- **Зачем.** Ручка — новый путь в обработке `WM_NCHITTEST` для окон с системной рамкой (раньше её касалась только своя
  рамка) и в X11 для любых окон. Ошибка даст либо мёртвую ручку, либо «залипший» курсор изменения размера над
  обычными элементами.
- **Приоритет:** желательно до выпуска 0.2.0 · ~10 минут.
- **Подготовка.**
  ```
  make -j8 all
  bin/gran_gallery samples/editor_frame.xml
  ```
  В Linux — `./bin/gran_gallery samples/editor_frame.xml --vulkan`; там же `samples/custom_window.xml` для своей рамки.
- **Шаги.**
  1. Наведите мышь на точки в правом нижнем углу строки состояния, затем на «UTF-8» рядом.
  2. Потяните за точки вниз-вправо и обратно.
  3. Разверните окно (двойной щелчок по заголовку), наведите на точки и попробуйте потянуть.
  4. Восстановите окно. В поле набирайте текст, затем выберите в меню «Файл → Сохранить».
- **На что смотреть.**
  - Шаг 1: над точками курсор «↘↖» (диагональ), над «UTF-8» — обычная стрелка.
  - Шаг 2: окно меняет размер за угол, как за край рамки; панель инструментов при этом прячет и возвращает кнопки.
  - Шаг 3: в развёрнутом окне точки размер не меняют, курсор обычный.
  - Шаг 4: строка состояния показывает «Команда: Сохранить».
- **Что прислать.** По шагам «прошло / нет»; ОС и рабочий стол.
- **Результат:** прошло по ручке и курсору (2026-11-12). **Попутно найдено:** в Linux у окна `editor_frame` нет кнопки «Свернуть» в заголовке.
- **Разбор:** кнопки «Свернуть» нет из-за настройки рабочего стола, не Грани: на стенде
  `gsettings get org.gnome.desktop.wm.preferences button-layout` = `':close'` (значение GNOME по умолчанию), Mutter
  рисует только крестик у всех окон X11. Проверка с включёнными кнопками — Т-40. Исправлений в коде нет.

## Т-33. Строка состояния с экранным диктором (Windows)

- **Зачем.** Живая область UI Automation (LiveSetting = Polite, событие LiveRegionChanged) — диктор должен прочесть
  новый текст секции, не уводя фокус из поля. Автотест видит только то, что событие ушло бы.
- **Приоритет:** желательно до выпуска 0.2.0 · ~5 минут.
- **Подготовка.** `bin/gran_gallery samples/editor_frame.xml`; Экранный диктор (Win+Ctrl+Enter); Inspect.exe.
- **Шаги.**
  1. Щёлкните в поле, нажмите Alt+Ф и С («Сохранить»), затем Alt+Ф и Н («Новый»).
  2. В Inspect наведите на строку состояния и на секцию «Строка 1, столбец 1».
- **На что смотреть.**
  - Шаг 1: после «Сохранить» диктор говорит «Команда: Сохранить» (или похоже), после «Новый» — «Команда: Новый»; курсор
    остаётся в поле, при загрузке окна строка состояния не зачитывалась.
  - Шаг 2: строка — ControlType StatusBar; секция — Text с именем «Строка 1, столбец 1», LiveSetting = Polite (1).
- **Что прислать.** Фразы диктора, снимок Inspect.
- **Результат:** прошло (2026-11-12).
