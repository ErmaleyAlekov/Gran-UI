## Т-25. Сохранение файла и захват кадра Vulkan в RenderDoc (Linux)

- **Зачем.** В Т-8 пример «Сохранить как…» ничего не записывал (исправлено: теперь пишет текстовый файл), а RenderDoc
  1.47 падал из-за второй копии RenderDoc — пакета Альт 1.31, зарегистрированного как системный слой Vulkan.
  Автоматика здесь слепа: диалог сохранения нужен живой, а захват — настоящий RenderDoc на настоящей карте.
- **Приоритет:** до выпуска · ~20 минут.
- **Подготовка.** Сборку с исправлением я положил в `~/gran-stand/rel`. RenderDoc:
  1. Удалите пакет Альт (он и сам не запускается):
     ```
     sudo apt-get remove renderdoc
     ```
     Если удалять не хотите — в шаге 3 в поле Environment Variables добавьте `DISABLE_VULKAN_RENDERDOC_CAPTURE_1_31=1`.
  2. Перенесите скачанный RenderDoc в папку без русских букв: из `~/Загрузки` qrenderdoc неверно вычисляет свой путь.
     ```
     mv ~/Загрузки/renderdoc_1.47 ~/renderdoc_1.47
     ```
  3. Запустите `~/renderdoc_1.47/bin/qrenderdoc`, щёлкните жёлтую строку «Vulkan capture is not configured» и
     согласитесь зарегистрировать слой (для своего пользователя). Строка должна исчезнуть.
- **Шаги.**
  1. Сохранение. В терминале:
     ```
     cd ~/gran-stand/rel
     ./bin/gran_gallery samples/platform.xml --vulkan
     ```
     Нажмите «Сохранить как…», оставьте имя `заметка Грани.txt`, папку — домашнюю, «Сохранить».
  2. В терминале: `cat ~/"заметка Грани.txt"`. Закройте галерею.
  3. Захват. В RenderDoc → вкладка Launch Application:
     - Executable Path: `/home/ermaley/gran-stand/rel/bin/gran_gallery`
     - Working Directory: `/home/ermaley/gran-stand/rel`
     - Command-line Arguments: `samples/showcase.xml --vulkan` (наберите руками, два дефиса)
     - Launch. Когда окно галереи появится — щёлкните в нём и нажмите F12 (или в RenderDoc — Capture Frame(s) Immediately).
  4. Закройте галерею. В RenderDoc в списке захватов правой кнопкой → Save — в `~/gran-stand/rdc/showcase.rdc`.
- **На что смотреть.**
  - Шаг 1: в строке состояния — «Сохранено: /home/ermaley/заметка Грани.txt»; ни «Не удалось…», ни «Отменено».
  - Шаг 2: напечатана строка «Грань UI: проверка сохранения файла / Gran UI: a file save check».
  - Шаг 3: окно галереи открылось, в RenderDoc у процесса указан API Vulkan, после F12 появился захват.
  - Если галерея сразу закрылась — в терминале RenderDoc последние строки и есть ли новый файл в
    `~/.local/state/GranGallery/crashes/`.
- **Что прислать.** По шагам «прошло / нет»; файл `.rdc` оставьте в `~/gran-stand/rdc/` — разберу сам
  (`renderdoccmd convert`: барьеры изображения цепочки обмена, число вызовов отрисовки, ошибки слоя).
