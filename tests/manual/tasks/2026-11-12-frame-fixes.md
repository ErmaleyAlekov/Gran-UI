## Т-38. Перетаскивание файлов в Linux: журнал сеанса XDND (Альт, GNOME на Wayland)

- **Зачем.** В Т-26 бросок из файлового менеджера не принимается, а самопроверка (`gran_linux_tests --window`:
  процесс-источник X11 бросает файл в зону) проходит. Разница: в GNOME на Wayland Nautilus — Wayland-программа, и
  протокол XDND для окна XWayland (им работает Грань) «переводит» Mutter. Вслепую не найти, на каком шаге он
  обрывается, поэтому окно теперь пишет каждый шаг сеанса в журнал: объявление XdndAware, начало (источник, версия,
  список типов), бросок (точка, принят ли), данные (тип, формат, байты, число путей).
- **Приоритет:** до выпуска 0.2.0 · ~5 минут.
- **Подготовка.**
  ```
  cd ~/gran-stand/rel
  ./bin/gran_gallery samples/platform.xml --vulkan
  ```
  Откройте в файловом менеджере папку `~/gran-xdnd`.
- **Шаги.**
  1. Перетащите `файл с пробелом.txt` на рамку «Перетащите сюда файлы…», отпустите.
  2. Закройте галерею. В терминале:
     ```
     grep -a " x11 " ~/.local/state/GranGallery/logs/GranGallery.log | tail -8
     ```
- **На что смотреть.**
  - Шаг 1: подсветилась ли рамка при наведении, появилось ли «Брошено файлов: 1».
  - Шаг 2: какие строки есть. Ожидаются: «окно … принимает перетаскивание файлов», «перетаскивание началось: … типы
    […], text/uri-list: yes», «бросок в точке (…), над зоной и с text/uri-list: yes», «данные броска: тип text/uri-list,
    формат 8, байт …, путей 1». Где цепочка оборвалась — там и ошибка.
- **Что прислать.** Ответ по шагу 1 и строки из шага 2 (можно снимком терминала).
- **Результат:** 2026-11-12: рамка подсвечивается при наведении, после отпускания ничего не меняется. В журнале три строки: XdndAware; начало — источник 4194308, версия 5, типы [application/x-gtk-local-dnd, text/plain;charset=utf-8, text/uri-list, application/vnd.portal.filetransfer, application/vnd.portal.files], text/uri-list: yes; бросок в (312, 327), принят. Строки «данные броска» нет. **Перепроверка после исправления (2026-11-12): прошло** — файлы принимаются.
- **Разбор:** **найдено и исправлено** 2026-11-12. Обрыв — между запросом данных и ответом: окно
  отправило XConvertSelection, но SelectionNotify уже не ждало. Мост Mutter, закончив перетаскивание на стороне
  Wayland, шлёт XdndLeave сразу после XdndDrop, а окно на Leave сбрасывало сеанс (флаг «ждём данные») и молча
  пропускало пришедшие данные. Теперь Leave после Drop, пока данные не получены, сеанс не кончает (`x11_drop.cpp`).
  **Человек нашёл, автоматика нет:** процесс-источник теста вёл себя как «вежливый» X11-менеджер. Теперь он, как
  Mutter, шлёт Leave сразу после Drop — без исправления тест окна падает («xdnd peer answers»), с ним проходит;
  тест также проверяет строки журнала сеанса. Журнал XDND оставлен: он и нашёл место обрыва.
  **Перепроверка:** повторите шаги 1–2 (сборка на стенде обновлена) — ожидается «Брошено файлов: 1» и строка «данные
  броска: тип text/uri-list, формат 8, …, путей 1»; затем шаги 3–5 из Т-26.

## Т-40. Кнопки «Свернуть» и «Развернуть» в GNOME (Альт)

- **Зачем.** В Т-32 у окна нет кнопки «Свернуть». Причина — настройка рабочего стола, не Грань: на стенде
  `org.gnome.desktop.wm.preferences button-layout` = `':close'` (так в GNOME по умолчанию), и Mutter рисует только
  крестик у всех окон X11. Проверим, что с включёнными кнопками окно Грани сворачивается и разворачивается.
- **Приоритет:** когда будет время · ~3 минуты.
- **Подготовка.** Включите кнопки (настройка вашего пользователя, вернуть — шаг 4):
  ```
  gsettings set org.gnome.desktop.wm.preferences button-layout ':minimize,maximize,close'
  ```
- **Шаги.**
  1. `cd ~/gran-stand/rel && ./bin/gran_gallery samples/editor_frame.xml --vulkan`.
  2. Нажмите «Свернуть», верните окно из панели задач (Super → значок окна).
  3. Нажмите «Развернуть», затем ещё раз.
  4. Если кнопки не нужны: `gsettings reset org.gnome.desktop.wm.preferences button-layout`.
- **На что смотреть.** Шаг 1: в заголовке три кнопки. Шаг 2: окно свернулось и вернулось с тем же содержимым.
  Шаг 3: окно на весь экран и обратно, строка состояния у нижнего края.
- **Что прислать.** «Прошло / нет»; при ошибке — снимок.
- **Результат:** прошло (2026-11-12).
