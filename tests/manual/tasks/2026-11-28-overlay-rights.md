## Т-254. Права элемента и проверка операций профиля

Сначала пройдите [общие пункты ревью кода О-1…О-8](../README.md#code-review-rules), затем переходите к шагам этой задачи.

**Зачем.** Проследите, как ближайшее явное правило ограничивает изменения дерева, включая пустой список прав.

**Приоритет.** Желательно до выпуска. Оценка — 16 минут.

**Подготовка.** Откройте [папку снимка Т-254](../review/T-254/) в редакторе. Сборка для чтения кода не требуется.

**Что читать**

- `src/markup/customization.cpp:12–45`
- `src/markup/overlay_targets.cpp:8–45`
- `src/markup/overlay_placement.cpp:7–80`
- `src/markup/overlay.cpp:24–99`

**Шаги и критерии.** Уделите особое внимание О-1, О-3, О-4, О-5.

1. Сравните пустое правило с отсутствующим при подъёме к родителю. Первое должно остановить наследование. См. `src/markup/customization.cpp:12–45`.
2. Проверьте поиск исчезнувшего id. Последующие операции должны адресовать только существующие узлы. См. `src/markup/overlay_targets.cpp:8–45`.
3. Проследите перенос между контейнерами и перестановку внутри одного. Проверьте независимые права move и insert и запрет цикла. См. `src/markup/overlay_placement.cpp:7–80`.
4. Проследите ошибку последней операции. Базовый документ должен остаться пригодным для следующей попытки. См. `src/markup/overlay.cpp:24–99`.

5. Сверьте разрешения экземпляра после его присоединения. Добавление в закреплённую панель с insert должно учитывать явные move, command и style на шаблоне. Ошибка стиля должна отклонить вставку целиком.

**Что прислать.** Укажите путь и строку, последовательность действий и нарушенный контракт. Запишите наблюдения в разделе ниже.
