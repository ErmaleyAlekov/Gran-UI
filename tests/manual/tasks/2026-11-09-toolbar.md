# Ручные проверки: панель инструментов ToolBar (0.2.0, часть 3 плана 2.1), 2026-11-09

Автотесты (`tool_bar_tests.cpp`) проверяют пункты-зеркала меню «ещё», уход хвоста при нехватке места и возврат при
расширении, `overflowMode="always"`, открытие меню «ещё» с клавиатуры и выполнение пункта. Чего они не видят: живое
изменение размера окна (кнопки «прыгают» ли между панелью и меню, мерцание), вид плоских кнопок и стрелки «ещё»,
фокус в поле при щелчках по панели, работу диктора.

## Т-30. Панель инструментов при изменении размера окна (Windows, Linux)

- **Зачем.** Уход кнопок в меню решается при каждой компоновке; ошибка в порядке или в замере даст «мигающую»
  кнопку на границе, потерянную кнопку (ни в панели, ни в меню) или меню «ещё» не с теми пунктами.
- **Приоритет:** желательно до выпуска 0.2.0 · ~10 минут.
- **Подготовка.**
  ```
  make -j8 all
  bin/gran_gallery samples/editor_frame.xml
  ```
  В Linux — `./bin/gran_gallery samples/editor_frame.xml --vulkan`.
- **Шаги.**
  1. Щёлкните в поле текста, наберите «абв». Щёлкните по стрелке «ещё» в конце панели.
  2. Выберите в меню «Справка».
  3. Медленно сужайте окно за правый край до самого узкого, затем медленно расширяйте обратно.
  4. В узком окне откройте «ещё», стрелками выберите «Отменить» (он выключен, пока нечего отменять) и «Найти…», Enter.
  5. В широком окне нажмите значок «Сохранить» (дискета), затем наберите «г».
  6. Tab по панели: до стрелки «ещё», Enter, Esc.
- **На что смотреть.**
  - Шаг 1: открылось меню с одним пунктом «Справка» (у неё `overflowMode="always"`); курсор в поле не пропал.
  - Шаг 2: в строке состояния «Команда: Справка».
  - Шаг 3: кнопки уходят с правого края по одной (группа «Отменить/Повторить» — обе сразу), стрелка «ещё» всегда
    последняя; при расширении возвращаются в том же порядке; ничего не мигает на границе, стрелка не прыгает.
  - Шаг 4: в меню те же кнопки по порядку, разделитель — горизонтальная линия, выключенные пункты серые и не
    выбираются; «Найти…» → «Команда: Найти…».
  - Шаг 5: «Команда: Сохранить»; «г» напечаталась после «абв» (фокус остался в поле).
  - Шаг 6: стрелка «ещё» получает рамку фокуса, Enter открывает меню с фокусом на первом пункте.
- **Что прислать.** По шагам «прошло / нет»; при «мигании» — запись экрана или снимок, ширину окна.
- **Результат:** прошло (2026-11-12, Windows и Linux).

## Т-31. Панель инструментов с диктором и Inspect (Windows)

- **Зачем.** Кнопка «ещё» рисует только стрелку; её имя для диктора — из каталога сообщений. Кнопки-значки читаются
  по `tooltip`. Проверяет только живой клиент UI Automation.
- **Приоритет:** когда будет время · ~5 минут.
- **Подготовка.** `bin/gran_gallery samples/editor_frame.xml`; Экранный диктор (Win+Ctrl+Enter), Inspect.exe.
- **Шаги.** Tab по кнопкам панели до стрелки; в Inspect — панель, разделитель, стрелка.
- **На что смотреть.** Диктор читает «Новый документ, кнопка», …, «Ещё, кнопка»; Inspect: панель — ToolBar,
  разделитель — Separator, стрелка — Button с именем «Ещё».
- **Что прислать.** Фразы диктора, снимок Inspect.
- **Результат:** прошло (2026-11-12).
